# Random Functions

### `random(x)`: number

Returns a random floating-point number between 0 and x.

**Arguments:**
| Name | Type | Description |
|------|------|-------------|
| `x` | number | Upper bound |

**Returns:** number

---

### `irandom(x)`: number

Returns a random integer between 0 and x.

**Arguments:**
| Name | Type | Description |
|------|------|-------------|
| `x` | number | Upper bound |

**Returns:** number

---

### `random_range(x1, x2)`: number

Returns a random floating-point number between x1 and x2.

**Arguments:**
| Name | Type | Description |
|------|------|-------------|
| `x1` | number | Lower bound |
| `x2` | number | Upper bound |

**Returns:** number

---

### `irandom_range(x1, x2)`: number

Returns a random integer between x1 and x2.

**Arguments:**
| Name | Type | Description |
|------|------|-------------|
| `x1` | number | Lower bound |
| `x2` | number | Upper bound |

**Returns:** number

---

### `choose(array)`: any

Returns a random element from an array.

**Arguments:**
| Name | Type | Description |
|------|------|-------------|
| `array` | array | Array to choose from |

**Returns:** any

---

### `chance(probability)`: boolean

Returns true with the given probability (0-1).

**Arguments:**
| Name | Type | Description |
|------|------|-------------|
| `probability` | number | Probability (0.0 to 1.0) |

**Returns:** boolean

---
