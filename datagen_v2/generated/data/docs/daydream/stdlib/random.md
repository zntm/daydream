# Randomness

### `random(n)`: number

Returns a random number between 0 and n.

**Arguments:**
| Name | Type   | Description            |
| ---- | ------ | ---------------------- |
| `n`  | number | Upper bound (Optional) |

**Returns:** number

---

### `random_range(min, max)`: number

Returns a random number between min and max.

**Arguments:**
| Name  | Type   | Description |
| ----- | ------ | ----------- |
| `min` | number | Lower bound |
| `max` | number | Upper bound |

**Returns:** number

---

### `irandom(n)`: number

Returns a random integer between 0 and n.

**Arguments:**
| Name | Type   | Description            |
| ---- | ------ | ---------------------- |
| `n`  | number | Upper bound (Optional) |

**Returns:** number

---

### `irandom_range(min, max)`: number

Returns a random integer between min and max.

**Arguments:**
| Name  | Type   | Description |
| ----- | ------ | ----------- |
| `min` | number | Lower bound |
| `max` | number | Upper bound |

**Returns:** number

---

### `chance(prob)`: boolean

Returns true with a probability of p (0-1).

**Arguments:**
| Name   | Type   | Description |
| ------ | ------ | ----------- |
| `prob` | number | Probability |

**Returns:** boolean

---

### `choose(values)`: any

Randomly chooses one of the provided values.

**Arguments:**
| Name     | Type | Description           |
| -------- | ---- | --------------------- |
| `values` | any  | Values to choose from |

**Returns:** any

---
