# Rendering

## Functions

### `render_rectangle(x1, y1, x2, y2, outline)`: void

Draws a rectangle.

**Arguments:**
| Name | Type | Description |
|------|------|-------------|
| `x1` | number | Left |
| `y1` | number | Top |
| `x2` | number | Right |
| `y2` | number | Bottom |
| `outline` | boolean | Draw outline only (Optional) |

**Returns:** void

---

| `x` | number | Center X |
| `y` | number | Center Y |
| `r` | number | Radius |
