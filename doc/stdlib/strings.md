# Strings and Types

### `string(val)`: String

Converts the given value to a string representation.

```javascript
string(123); // "123"
```

### `typeof(val)`: String

Returns a string describing the type of the value ("number", "string", "boolean", "array", "struct", "function", "undefined", "object").

```javascript
typeof 123; // "number"
typeof "hi"; // "string"
```

### `is_string(val)`: Boolean

Returns true if the value is a string.

### `is_real(val)`: Boolean

Returns true if the value is a number (real).

### `is_bool(val)`: Boolean

Returns true if the value is a boolean.

### `is_array(val)`: Boolean

Returns true if the value is an array.

### `is_struct(val)`: Boolean

Returns true if the value is a struct.

### `is_undefined(val)`: Boolean

Returns true if the value is undefined.
