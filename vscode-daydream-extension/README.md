# Proglang VS Code Extension

This extension provides syntax highlighting for Proglang (`.daydream`) files.

## Features

-   Syntax highlighting for keywords, control flow, functions, variables, and literals.
-   Bracket matching and auto-closing.
-   Comment toggling support.

## Installation

### Development Mode

1. Open this `vscode-proglang` folder in VS Code.
2. Press `F5` to launch a new Extension Development Host window.
3. Open any `.daydream` file to see the highlighting in action.

### Manual Installation

1. Copy the `vscode-proglang` folder to your VS Code extensions directory:
    - **Windows**: `%USERPROFILE%\.vscode\extensions\`
    - **macOS/Linux**: `~/.vscode/extensions/`
2. Restart VS Code.
